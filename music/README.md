# 공용 곡 (music/)

이 폴더의 곡은 사이트(GitHub Pages)에 그대로 공개되어, 누구나 듣고 내려받을 수 있습니다.

## 올려도 되는 곡
- 직접 만들거나 녹음한 곡
- 저작권이 끝났거나 자유 이용이 허락된 곡 (예: CC0, CC BY — 출처 표시 조건은 지킨다)
- 유튜브 오디오 라이브러리, Pixabay Music 등에서 "재배포 가능"으로 받은 곡

시판 음원(멜론·유튜브 등에서 받은 가요·팝)은 올리지 않습니다. 공개 저장소에 올리면 배포가 됩니다.

## 올리는 법
1. 무대에 맞는 폴더에 음원을 넣는다: `club/`(CLUB PULSE), `live7080/`(7080), `jazz/`(재즈 바)
2. 가사가 있으면 같은 이름의 `.lrc` 파일을 옆에 둔다 (예: `밤비.mp3` + `밤비.lrc`)
3. `python build_music.py` 를 실행해 `tracks.json`을 다시 만든다
4. 커밋하고 푸시한다

파일 하나는 100MB를 넘을 수 없습니다. mp3(192kbps 안팎)를 권장합니다.
